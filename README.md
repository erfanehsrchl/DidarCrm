# پروژه بازطراحی Activity در Didar CRM

این Repository یک تمرین بازطراحی تدریجی با استفاده از .NET 8، SQL Server، RabbitMQ و Clean Architecture است.

پروژه اکنون در مرحله Bootstrap قرار دارد. مرجع زنده محدوده، تصمیم‌های معماری و مراحل پیاده‌سازی در فایل [`PROJECT_PLAN.md`](PROJECT_PLAN.md) نگهداری می‌شود.

## وضعیت فعلی

مرحله ۰، شامل ساخت Solution و برنامه‌ریزی، آماده بازبینی است. هنوز قابلیت تجاری پروژه پیاده‌سازی نشده است.
